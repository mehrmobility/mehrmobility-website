# Mehr website preview assets

The owner requested a redesign of mehrkhodro.co. These assets are retained for that local redesign, not relicensed for unrelated uses.

- `bakh-regular.woff2`, `bakh-bold.woff2`, `bakh-extrabold.woff2`: official site's existing YekanBakhFaNum webfonts under `/wp-content/uploads/2023/08/`.
- `mehr-logo.png`: `https://mehrkhodro.co/wp-content/uploads/2023/07/Mehr-Khodro-4.png`.
- `mehr-wordmark.png`: `https://mehrkhodro.co/wp-content/uploads/2024/08/Mehr-Khodro-1.png` (retained original; white artwork).
- `hilux-grs.png`: `https://mehrkhodro.co/wp-content/uploads/2023/09/HILUX-GRS-1.png`.
- `vehicles/*`: exact `primaryImage.url` values from `lib/mehr-site/vehicles.json`.
- `content/*`: exact same-domain `displayImage` values from `lib/mehr-site/editorial.json`.
- The header reuses `/brand/mehr-symbol.png`, already supplied with the owner's existing project.

The 52 catalog/editorial primary images were fetched using `scripts/fetch-mehr-site-assets.mjs`. No car images were generated or substituted for factual models. Some source artwork contains existing third-party trademarks or publisher marks; no ownership claim is made. Owner should verify font and media licensing before distribution on a new host.
