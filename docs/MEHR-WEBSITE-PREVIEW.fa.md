# نسخه اولیه بازطراحی سایت عمومی مهر

تاریخ: ۲۰۲۶-۰۹-۱۰

به‌روزرسانی تجربه مشتری: هشت مسیر جدید برای راهنمای انتخاب، مقایسه، گاراژ همین‌دستگاه، نمایشگاه تصویری، محاسبه شخصی خرید، پیش‌نویس معاوضه/بازدید/خدمات و ورودی پرتال اضافه شده است. وضعیت عملیاتی، مرز داده‌ها و الزامات اتصال در [راهنمای تجربه‌های مهر](MEHR-EXPERIENCES.fa.md) آمده است. محدودیت‌های نسخه اولیه زیر، تا جایی که در آن راهنما تصریح نشده، همچنان برقرارند.

## اجرا و مرز پروژه

پیش‌نمایش: `http://127.0.0.1:3001/mehr`

فرمان فعلی پروژه `npm run dev` است. پرتال مشتریان در `/` و API آن در `/customer-api/v1` دست‌نخورده مانده‌اند. مسیرها، داده‌ها، اجزا و CSS سایت عمومی در namespace جداگانه `mehr` قرار دارند. هنوز یک بسته استقرار مستقل نیست؛ برای انتشار روی دامنه باید از پروژه پرتال جدا و به میزبان انتخاب‌شده منتقل شود. هیچ انتشار، تغییر DNS، آپلود کد پرتال یا اتصال به دیتابیس داخلی انجام نشده است.

## مبنای هویت بصری

- لوگو و نشان واقعی مهر از دارایی‌های موجود و سایت رسمی.
- رنگ اصلی `#FF2222`، سفید، مشکی و زمینه `#F5F5F5` از CSS رسمی سایت فعلی.
- فونت YekanBakhFaNum در وزن‌های Regular، Bold و ExtraBold از فایل‌های سایت موجود؛ فایل‌ها محلی شده‌اند.
- مرجع رنگ و تایپوگرافی: `https://mehrkhodro.co/wp-content/uploads/elementor/css/post-6.css`.
- راهنمای رسمی CI شامل قواعد ابعاد، حریم لوگو و هویت دفاتر در فایل‌های بررسی‌شده یافت نشد. این نسخه بر هویت موجود سایت تکیه دارد، نه ادعای انطباق تأییدشده با دفترچه CI.
- عبارت‌ها و ترکیب‌بندی صفحه اصلی، پیشنهاد طراحی این نسخه هستند و شعار رسمیِ تأییدشده تلقی نمی‌شوند.

## محتوای واردشده

- ۳۰ خودرو از ۹ برند، با ویژگی‌های دسته‌بندی و متن منتشرشده عمومی.
- ۲۷ لینک کاتالوگ، ۲۷۱ پیوند گالری در ۲۶ خودرو و ۳ جدول فنی کامل.
- ۱۰ مقاله، ۴ اطلاعیه، ۷ خدمت و محتوای درباره ما/تبدیل پلاک.
- اصل دو PDF نظرسنجی و شکایت، شعب و راه‌های ارتباط.
- یک دیدگاه عمومی با تاریخ و نام نمایشی؛ بدون ایمیل یا داده خصوصی.
- ۵۲ تصویر اصلی خودرو/مقاله/خدمت در `public/mehr-site` محلی شده‌اند. گالری‌ها، تصاویر داخل مطالب و PDFها هنوز به نشانی منبع متصل‌اند.

متن سه خودرو که در تب سایت قبلی دیده نمی‌شد، از محتوای منتشرشده API عمومی بازیابی شده است. متن‌های لورم خدمات وارد نمایش نشده‌اند؛ توضیح کوتاه عمومی و مسیر تماس جای آن‌ها آمده است. جدول کرولا کراس به‌دلیل نام متفاوت در منبع، همراه هشدار تأیید اطلاعات نمایش داده می‌شود. تاریخ اطلاعیه‌های قدیمی حفظ شده و به‌عنوان فروش فعال معرفی نمی‌شوند.

## امکانات نسخه اولیه

- صفحه اصلی، اسلایدر سه خودرو، فهرست برندها، خودروهای منتخب، خدمات، مجله و اطلاعیه‌ها.
- جست‌وجو، فیلتر چندگانه، مرتب‌سازی سال/نام، چیپ فیلتر، حالت بدون نتیجه و صفحه‌بندی خودروها.
- صفحات اختصاصی خودرو، تب‌ها، گالری بزرگ‌نمایی‌شونده، جدول، نمایش و دانلود PDF، خودروهای مرتبط و فرم مشاوره پیش‌پرشده.
- صفحات مقاله/اطلاعیه با محتوای اصلی، تصاویر، پیوست، دیدگاه و اشتراک‌گذاری.
- هفت صفحه خدمت و پیش‌نمایش سه‌مرحله‌ای نوبت‌گیری.
- امور مشتریان، اسناد، راه‌های ارتباط، نقشه شعب، درباره مهر و تبدیل پلاک.
- نسخه واکنش‌گرا، منوی موبایل، فوکوس صفحه‌کلید، دیالوگ native و پشتیبانی کاهش حرکت.
- عنوان صفحات و `noindex` برای جلوگیری از ایندکس‌شدن نمونه.

## محدودیت‌های صریح

1. فرم‌ها اطلاعات را فقط در حافظه رابط برای کنترل اعتبار نگه می‌دارند؛ هیچ ذخیره محلی پایدار، ارسال، ایمیل، پیامک یا CRM وجود ندارد. نتیجه فرم صریحاً «ارسال نشده» است.
2. ساعت‌های رزرو نمونه‌اند و ظرفیت واقعی ندارند. مبلغ، درگاه، فاکتور یا رزرو قطعی ایجاد نمی‌شود.
3. حساب مشتری، وضعیت قرارداد، ویدئوی اختصاصی و مدارک شخصی به سایت عمومی متصل نشده‌اند.
4. صفحات خالی/نمونه سایت قبلی به‌عنوان فروشگاه یا پنل فعال بازسازی نشده‌اند. انتقال دائمی برای محتوای دارای معادل واقعی و مسیرهای کلیدی آماده است؛ taxonomyها، برچسب‌های کم‌ارزش و همه ۱۵۱ نشانی باید پیش از انتشار با گزارش Search Console و تصمیم مالک محتوا بازبینی شوند.
5. فایل‌های ناقص منبع، اعتبار حقوقی اسناد، قیمت‌ها، نشان‌های ظرفیت فروش و یکسان‌سازی نام حقوقی نیازمند تأیید مالک محتوا هستند.
6. فرم خرید شهر را به‌صورت متن آزاد می‌پذیرد؛ چند شهر برای پیشنهاد آورده شده‌اند. فهرست بسته قبلی، محدودیت جدید ایجاد نمی‌کند.
7. این تحویل نسخه اولیه قابل بررسی است؛ گواهی تکمیل تمام معیارهای انتشارِ ماتریس ممیزی نیست.

## کنترل‌های انجام‌شده

- `next typegen`، TypeScript و build پروژه.
- ESLint محدوده جدید: بدون خطا؛ ۱۳ هشدار توصیه استفاده از Next Image برای تصاویر فعلی باقی است. پیکربندی پروژه از قبل تصاویر را unoptimized می‌کند.
- تطبیق تعداد خودرو، برند، کاتالوگ، گالری، محتوای مجله و خدمات.
- آزمون مستقل جست‌وجوی Fronx، فیلتر Suzuki، حالت بدون نتیجه و نرمال‌سازی حروف/اعداد فارسی.
- کنترل وجود ۵۲ تصویر اصلی محلی و نبود script، form، iframe، handler یا لینک اجرایی در HTML واردشده مقالات.
- کنترل HTTP تمام ۶۴ مسیر: پاسخ 200، پوسته مهر و noindex تأیید شد؛ خودروی نامعتبر 404 می‌دهد؛ فیلتر Suzuki در HTML سرور دو کارت برمی‌گرداند؛ مسیر پرتال قبلی `/` همچنان 200 است.
- آزمون بازاجرا: `node scripts/check-mehr-site.mjs` با dev server روشن. این فرمان فقط GET محلی می‌فرستد و هیچ فرم یا درخواست واقعی ایجاد نمی‌کند.
- طبق راهنمای Sites، آزمون تعاملی/تصویری مرورگر بدون درخواست صریح کاربر انجام نشده است. CSS واکنش‌گرا نوشته شده، اما تست بصری موبایل هنوز انجام نشده است.
- ابزار خواندنی WebMCP برای جست‌وجوی کاتالوگ با feature detection و cleanup اضافه شده؛ محیط معتبر برای آزمون WebMCP در ابزارهای فعال یافت نشد. ثبت و اجرا در مرورگر پشتیبان تأیید نشده است.

## قبل از انتشار مستقل

تأیید طراحی و نسخه معتبر CI؛ تأیید محتوای حقوقی و نام شرکت؛ خروجی کامل رسانه و metadata؛ بازبینی نهایی نگاشت مهاجرت و روشن‌سازی جایگاه پرتال مستقل در دامنه؛ CMS و نقش‌ها؛ backend فرم‌ها و اعلان‌ها؛ سازوکار واقعی نوبت/پرداخت؛ رضایت و rate limit؛ آزمون مرورگر/موبایل، دسترس‌پذیری و کارایی؛ سپس استقرار جدا از پرتال و برنامه بازگشت.
